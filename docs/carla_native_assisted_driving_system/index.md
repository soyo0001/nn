## 项目简介
本项目依托 **CARLA 0.9.14自动驾驶仿真平台**，融合传统机器视觉与PID控制算法，实现了环境感知、决策规划、车辆控制全流程闭环验证，覆盖多种城市道路场景与天气状况，规避了真实道路测试成本高、风险大的问题。

项目通过纯视觉方案实现多类交通元素识别与车辆自动控制，可在仿真环境中稳定实现车道保持、定速巡航、安全预警与自动避让，完整还原了智能辅助驾驶系统的核心功能。

---

## 核心功能特点
1.  **多模态环境感知**
    - 基于图像识别的交通信号灯（红/黄/绿）状态识别，实现红绿灯自动通行控制
    - 交通标志（停车牌/限速牌）识别，支持限速切换与强制停车控制
    - 行人检测与AEB自动紧急刹车，优先响应行人避让
    - 车道偏离预警（LDW），实时监测车道线并触发预警
    - 前向碰撞预警（FCW）+前方障碍物智能减速避让
    - 盲区监测预警（BSD），提升变道场景安全性
    - 天气智能识别，自动自适应控制车辆近光灯/雾灯开关

2.  **稳定车辆控制逻辑**
    - PID定速巡航，保持目标车速平稳行驶
    - 车道居中控制，实现无偏移车道保持
    - 多层级控制优先级：`行人AEB > 停车牌 > 红绿灯 > 障碍物避让 > 定速巡航`，保障行驶安全

3.  **全仿真闭环验证**
    - 基于CARLA虚拟城市多场景、多天气测试
    - 一键启动运行，支持Windows环境直接仿真
    - 完整可视化交互，支持多视角切换、天气切换调试

## 运行环境与安装步骤
### 基础环境要求
| 项目 | 版本要求 |
| :--- | :--- |
| Python | 3.7 / 3.8 |
| 仿真平台 | CARLA Simulator 0.9.14 |
| 依赖库 | pygame、opencv-python、numpy |
| 系统支持 | Windows 10 / 11 |

### 完整安装流程
1.  **克隆项目代码仓库**
    ```bash
    git clone 你的项目仓库地址
    cd 你的项目文件夹
    ```

2.  **启动CARLA仿真器**
    进入CARLA安装目录，运行 `CarlaUE4.exe`，等待仿真服务端口2000启动完成。

3.  **一键安装全部Python依赖**
    ```bash
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
    ```

## 功能模块说明
| 模块名称 | 功能描述 |
| :--- | :--- |
| 定速巡航模块 | 基于PID控制器实现目标车速稳定控制，支持动态调整 |
| 车道保持模块 | 识别车道线并实时修正方向盘，保持车辆居中行驶 |
| 交通灯识别模块 | 识别红/黄/绿三色信号灯，实现红灯停车、绿灯通行 |
| 交通标志识别模块 | 识别停车牌/限速牌，触发停车或车速调整 |
| 行人AEB模块 | 检测前方行人并触发紧急制动，为最高优先级控制 |
| 障碍物避让模块 | 检测前方车辆/障碍物，自动减速或避让 |
| 车道偏离预警 | 车辆压线时触发屏幕警告与提示音 |
| 天气自适应车灯 | 根据昼夜/雨雾天气自动开关近光灯/雾灯 |
| 盲区监测预警 | 监测车辆盲区，提升变道安全性 |
